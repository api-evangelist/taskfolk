# Taskfolk

Project management and issue tracking platform for teams and AI agents. Offers boards, sprints, docs, OKRs, automations, and first-class agent support via a REST API, hosted MCP server, and installable agent skills.

- **Provider:** https://taskfolk.ai
- **Documentation:** https://taskfolk.ai/developer
- **Base URL:** https://taskfolk.ai/api
- **Tags:** project-management, issue-tracking, task-management, productivity, collaboration, mcp, ai-agents, agent-native, rest-api, openapi, webhooks, oauth2
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** yes

## APIs

- **Taskfolk API** — First-party REST API (~180 operations) covering issues, projects, sprints, comments, agents, docs, goals, forms, automations, chat, and webhooks. Bearer API key auth, cursor pagination, signed webhooks. Also exposes a hosted MCP server over Streamable HTTP. (`https://taskfolk.ai/api`)

> The MCP server was confirmed first-party rather than via a third-party directory: it is listed in
